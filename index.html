    Questions

    Is it free?
    Yes. On lz-rewrite.pages.dev, rewrites run on a hosted AI with a fair-use limit of 10 a minute and 60 a day per visitor. If you need more, add your own Anthropic API key in Settings and usage is billed to your account.
    What happens to the text I paste?
    Your draft is sent once to generate the rewrite, either through Rewrite's server function or straight to Anthropic if you use your own key. The server doesn't log or store it. Your history and favourites are saved only in this browser.
    What is demo mode?
    If the hosted AI isn't available, for example on the GitHub Pages mirror, and you haven't added a key, Rewrite plays pre-written rewrites of the eight templates so you can still see how it works. Add a key in Settings to rewrite your own messages.
    Will it change my facts?
    It's told to keep every name, date, number and commitment, and never invent details. Anything it can't know, like your name, becomes a placeholder such as [Your name]. Turn on Highlight changes to check every edit.
    Does it work in other languages?
    Yes. It replies in the language of your draft. For English, it matches your spelling, and uses Australian English when it can't tell.
    Is my API key safe?
    A key you add is stored only in this browser and sent only to api.anthropic.com. Press Forget key in Settings to remove it, which is worth doing on a shared computer.
